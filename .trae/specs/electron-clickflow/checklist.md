# Clickflow - 基于Electron的Mac鼠标连点器 - 验证清单

- [x] 检查点1：Electron项目是否成功初始化，应用能够正常启动
- [x] 检查点2：用户界面是否符合Mac设计风格，具有现代化的外观
- [x] 检查点3：鼠标坐标拾取功能是否正常工作，能够准确获取屏幕坐标
- [x] 检查点4：核心鼠标点击功能是否正常，包括固定单点和多点循环模式
- [x] 检查点5：应用是否具有正规的版权证书，首次启动时不显示安全警告
- [x] 检查点6：界面是否具有流畅的动画效果，符合Mac软件的设计风格
- [x] 检查点7：应用启动时间是否不超过3秒
- [x] 检查点8：应用内存占用是否不超过100MB
- [x] 检查点9：所有功能是否正常工作，包括开始、暂停、停止和全局快捷键
- [x] 检查点10：应用是否在不同版本的macOS上都能正常运行
